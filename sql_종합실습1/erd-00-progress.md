# 학사관리시스템 ERD 설계 진행표

이 문서는 강의자료 44쪽의 ERD 작성 순서에 따라 진행 상태와 승인 여부를 기록한다.

## 진행 원칙

- 각 단계의 작업계획을 먼저 작성하고 사용자 승인을 받은 후 작업한다.
- 각 단계의 결과물을 사용자에게 제시하고 검토 승인을 받은 후 다음 단계로 이동한다.
- 수정 요청이 있으면 해당 단계의 결과물을 보완하고 다시 검토받는다.
- `[ ]`는 미완료, `[x]`는 완료를 뜻한다.
